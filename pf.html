Understanding the M-δ Limit Definition

To rigorously prove that , we must show that for every negative number $M < 0$, there exists a positive distance $\delta > 0$ such that whenever $x$ is within distance $\delta$ to the left of $2$ ($2 - \delta < x < 2$), the function value $f(x)$ drops strictly below $M$.

$$\forall M < 0, \exists \delta > 0 \text{ s.t. } 0 < 2 - x < \delta \implies \frac{1}{(x-2)^3} < M$$

Why $\delta = \min\left(1, \frac{1}{|M|}\right)$?
If we set $\delta \le 1$, then $|x-2| < 1$. When a positive fraction is less than $1$, cubing it makes it smaller ($|x-2|^3 < |x-2|$). Thus, we don't need cube root functions ($\sqrt[3]{|M|}$)! We simply guarantee $|x-2|^3 < |x-2| < \delta \le \frac{1}{|M|}$.
