LEGO EV3 Sumo Robot Camp

4-Day Intensive Curriculum | 2 Hours Per Session

Day 1: EV3 Kit Setup & Precision Driving Base

120 Minutes

📢 First 5 Minutes: Today's Mission

  • Goal: Unpack, sort, and assemble your EV3 Driving Base.
  • Challenge: Drive as close to the target line as possible without knocking over the marker (3 attempts)!
  • Rules: Must strictly manage your parts and leave 5 minutes at the end for inspection.

🎯 Daily Objective

Students will learn kit organization, assemble the standard EV3 driving base, set up basic VS Code workspace connections, and participate in a precision stop challenge.

📅 Agenda

Time Activity Details
0:00 - 0:05 Briefing & Goal Setting Present mission statement, rules, and daily target challenge.
0:05 - 0:50 Sorting & Kit Inventory Sort motors, sensors, beams, and pins using the storage trays. Verify core components.
0:50 - 1:45 Base Build & VS Code Intro Construct standard EV3 driving base. Install/verify VS Code EV3 extension connection.
1:45 - 1:55 Precision Stop Challenge 3 attempts per team to program the robot to stop as close to a marker as possible.
1:55 - 2:00 5-Minute Wrap-Up & Inspection Return loose parts to trays, turn off EV3 bricks, mentor inspection pass.

🧹 End-of-Day Rubric & Mentor Inspection

  • EV3 Brick powered down safely.
  • All small pins and beams placed in designated sorting tray compartments.
  • Workstation table wiped clear of loose pieces.

📝 Daily Summary

Day 1 establishes foundational hardware familiarity and initial software environment setup, emphasizing organization and basic motor control before moving into sensor integration.

Day 2: VS Code Movement & Color Sensor Edge Detection

120 Minutes

📢 First 5 Minutes: Today's Mission

  • Goal: Write Python code in VS Code for smooth movement, turning, and edge detection.
  • Challenge: Detect painter's tape line boundaries and turn back inside automatically!

🎯 Daily Objective

Students will master movement blocks and turns in VS Code, attach and calibrate the Color Sensor, and program their robot to recognize ring boundaries marked with painter's tape.

📅 Agenda

Time Activity Details
0:00 - 0:05 Briefing & Review Review Day 1 precision challenge results and introduce color sensor mission.
0:05 - 0:40 VS Code Movement & Turns Program precise tank steering, 90-degree, and 180-degree pivot turns in Python.
0:40 - 1:25 Color Sensor Mount & Setup Attach color sensor facing downward; write line detection logic (reflectance/color mode).
1:25 - 1:55 Edge Avoidance Challenge Test robot inside painter's tape ring. Robot must navigate continuously without crossing tape.
1:55 - 2:00 5-Minute Wrap-Up & Inspection Store custom builds safely, shut down laptops and bricks, mentor inspection.

🧹 End-of-Day Rubric & Mentor Inspection

  • VS Code projects saved and uploaded to EV3 brick.
  • Color sensor securely attached without dragging wires.
  • Workstation cleaned, cables neatly wrapped, kit closed.

📝 Daily Summary

Day 2 bridges simple locomotion with autonomous decision-making using sensor inputs, enabling robots to independently remain inside a designated sumo ring.

Day 3: Mechanical Gearing, PID Control & Prelims

120 Minutes

📢 First 5 Minutes: Today's Mission

  • Goal: Optimize torque via mechanical gearing and smooth tracking via PID algorithms.
  • Challenge: Begin preliminary Sumo matches in the second half of the day!

🎯 Daily Objective

Students will gear down motors for maximum pushing power, implement PID control logic for smooth line tracking/boundary recovery, and enter initial sumo tournament qualifying rounds.

📅 Agenda

Time Activity Details
0:00 - 0:05 Briefing & Strategy Discuss torque vs. speed trade-offs and introduce PID control concepts.
0:05 - 0:35 Gear Reductions & Rebuild Modify drive train with gear ratios designed to maximize pushing force.
0:35 - 1:15 PID Control Implementation Write proportional-integral-derivative logic in VS Code for accurate boundary tracking.
1:15 - 1:55 Sumo Preliminaries Run round-robin qualification matches on painter's tape board to seed final bracket.
1:55 - 2:00 5-Minute Wrap-Up & Inspection Record preliminary match scores, secure robots, mentor sign-off.

🧹 End-of-Day Rubric & Mentor Inspection

  • Gear train mesh alignment checked for smooth rotation.
  • PID code parameters documented in project notebook/file.
  • Quick 5-minute table cleanup completed.

📝 Daily Summary

Day 3 combines mechanical engineering principles with advanced software control algorithms, setting up robust performance for competition matches.

Day 4: Championship Finals & Full Disassembly

120 Minutes

📢 First 5 Minutes: Today's Mission

  • Goal: Compete in the Final Sumo Tournament and crown the Champion!
  • Mandatory Requirement: Dedicate the final 30 minutes to full robot disassembly and strict inventory check.

🎯 Daily Objective

Students will finalize robot code, compete in a double-elimination Sumo Tournament, and thoroughly disassemble and reorganize all kit components under mentor supervision.

📅 Agenda

Time Activity Details
0:00 - 0:05 Tournament Briefing Announce final bracket seeding and match rules.
0:05 - 0:30 Final Tuning & Open Practice Last-minute code tweaks, wheel traction checks, battery replacements.
0:30 - 1:25 Championship Tournament Execute final bracket matches on the sumo board. Announce winner & awards.
1:25 - 1:55 Full Disassembly & Sorting Deconstruct entire robot. Sort every component according to checklist.
1:55 - 2:00 Mentor Inspection & Graduation Final kit audit by mentors before dismissal.

📋 Final Disassembly & Kit Inventory Checklist (Mandatory)

Every team must verify the presence of all primary core components prior to mentor sign-off:

  • 1x EV3 Programmable Brick (Powered off, SD card removed)
  • 2x Large Servo Motors
  • 1x Medium Servo Motor
  • 1x Color Sensor & 1x Ultrasonic Sensor
  • 2x Main Drive Wheels & Hub Tires
  • 1x USB Cable & MicroSD Card
  • All Connecting Cables (35cm, 25cm, 50cm neatly bundled)
  • Structural Beams, Axles, & Pins fully sorted by color/length into tray sections

📝 Daily Summary

Day 4 culminates the camp experience through exciting competitive application while instilling discipline, stewardship, and proper hardware care during final teardown.
